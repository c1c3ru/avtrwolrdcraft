## Correção ao doc anterior
`docs/RECON_INTERIOR_NPCS.md` dizia que a aparência de cada id "não está nos dados locais". **Está.** `Resources/PremadeData/` tem **59 JSONs**
(`{"AvatarSpineDatas":[...]}`): `PremadeCharactersJson` (896 avatares, ids 100000–100903) mais um por cena mais nova (ids 1009xx–1013xx), **1.324 avatares** no total,
com ids **globalmente únicos**. Dos 389 NPCs dos 52 interiores, **386 (99,2%) resolvem**; os 3 restantes (`900005`, `900009`, `900017`) são pets, definidos por dado de cena
(`LevelCatPD`/`LevelDogPD {"id":...}`) e por `PetMaker_BreedsData` (CSV de 35 raças: Dog 19, Cat 14, Horse 2). Nota: antes eu havia dito "64 arquivos"; o número correto é 59.

## Esquema
`AvatarSpineData{ID, SkinsData[], SizeType, Config{isDisplayInPhone}, SpineType, BuildNumber}` (igual à declaração). Tipos: Character 1.226, Toddler 60, Baby 15, Dog 10, Horse 5, Cat 6, Car 2
(o formato também serve a carros, relevante ao L06). `SkinData{CategoryType, SkinName, Colors (Color32[]), ColorA, ColorB (Nullable<Color>)}` com três variantes no JSON.
Há **dois formatos de cor** que nunca se misturam num avatar: `ColorA/ColorB` (floats, legado) com `BuildNumber` 0–191 e `Colors` (bytes) com `BuildNumber` 195–1000. Ou seja, **`BuildNumber`
marca a migração do formato de cor**, o que responde com dado parte da unidade 4 do L03. `CategoryType` mapeia 1:1 para uma pasta de skin no Character (um erro de caixa, `Hair_back`, em 1 caso).

## Como o original carrega (provado em `libil2cpp.so`)
- `TryLoadPremadeListFromResources` lê todos os TextAssets de `PremadeData/`; JSON vazio, inválido ou `AvatarSpineDatas` nulo geram erro; um id já visto em outro arquivo gera
  `ID[n] is already in use in file name[x]!`. Nossos dados têm 0 duplicados.
- `LoadPremadeCharactersFromResources` (chamada por `AvatarSpineDataManager.Init`): lista → `PlayerPrefs.GetInt("CafeteriaPremadesTempOverrideKey")` → por avatar `TryLoadAvatarSpineData` →
  `SaveCharacter` (grava `AvatarSpineData_<id>`) → `SetInt` na chave. Os premades são **copiados para o save local**; a chave controla um refresh único (quais e a condição: não decodificado).
- `DestroyAvatar` de Character, Toddler, Baby, Cat, Dog e Horse recarrega o premade original (`TryLoadPremadeCharacterFromResources`); `LevelCharactersRandomizer.SpawnCharacter` chama
  `ResetPremadeCharacter`; o telefone (`ContactsPage`) e `LevelUIScrollCharacterItem` usam `IsPremadeID`; existe migração (`PerformAvatarSpineDataMigration`, `IsOldPremadePet`).
