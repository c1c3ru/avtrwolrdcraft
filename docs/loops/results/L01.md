## Contrato recuperado do callback `<LoadScene>b__0` (token 0x0600570f)
Ramo local (chama `GameSceneManager.LoadSceneImplement(sceneName)`) se qualquer um:
`sceneName == "Home"`, `considerMultiplayer == false`, `MPManager.IsMultiplayerGame == false`,
ou `MPManager.Instance.IsHostAndOnlyPlayer()`. `Instance` nulo levanta exceção.

Caso contrário, ramo multiplayer: `Guid.NewGuid().ToString()`; host faz
`new MPData_SceneChangeRequest` → `GetActiveSceneId` → `SendWaitForPlayerForSceneChangeRequest`;
não-host faz `GetActiveSceneId` → `TrySendEvent`; ambos seguem com
`DestroyAllGameObjectsInLoadedScenes` → `GetPlayerUID` → `ClearPlayerFromScenes` e retornam.
**Esse ramo não chama `LoadSceneImplement`**: a troca de cena ocorre depois, por evento de rede (inferência: não há prova do evento receptor).

## Limites
Janela linear até o próximo método metadata, sem CFG completo. Nomes dos campos estáticos vêm das
declarações Cpp2IL (offsets 0x0/0x38), não do binário. Nenhuma execução do original.
