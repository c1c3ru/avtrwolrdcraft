## Pipeline recuperado

`GameSceneManager.LoadScene(sceneName, considerMultiplayer = true, mp_nextSceneId = null)` (0x20728d4):

1. Se `IsSceneChangingInProgress` (static +0x30): `Debug.LogError("Scene loading is already in progress!")` e retorna.
2. Limpa caches, nesta ordem: `AvatarSpineTexturesManager.ClearAllTextureData`, `SUTUtils.ClearTexturesCache`, `CarPartsLoader.ClearLoadedParts`, `CarAppearance.ClearIconCache`.
3. `IsSceneChangingInProgress = true`; `CurrentlyLoadingSceneName = sceneName`; `PreviousSceneName = GetActiveSceneName()`.
4. Invoca `OnBeforeSceneLoadStage1/2/3Action`, nessa ordem, cada uma só se não nula.
5. `LoadingScreenManager.Instance.StartSceneTransition(new Action(closure, <LoadScene>b__0))`; `Instance` nulo levanta exceção.

Closure `<>c__DisplayClass28_0` guarda `sceneName` (+0x10), `considerMultiplayer` (+0x18), `mp_nextSceneId` (+0x20).

Callback `<LoadScene>b__0` (token 0x0600570f, 0x2073488): ramo local (`LoadSceneImplement(sceneName)`) se
`sceneName == "Home"`, ou `considerMultiplayer == false`, ou `MPManager.IsMultiplayerGame == false`, ou
`MPManager.Instance.IsHostAndOnlyPlayer()`. Caso contrário, ramo multiplayer: `Guid.NewGuid().ToString()`; host →
`new MPData_SceneChangeRequest` → `GetActiveSceneId` → `SendWaitForPlayerForSceneChangeRequest`; não-host →
`GetActiveSceneId` → `TrySendEvent`; ambos → `DestroyAllGameObjectsInLoadedScenes` → `GetPlayerUID` →
`ClearPlayerFromScenes` → retorna. **Esse ramo não chama `LoadSceneImplement`.**

`LoadSceneImplement(sceneName)` (0x2072cc8): se `MPManager.IsMultiplayerGame`, `MPOwnership.Clear()`; depois tail call
`SceneManager.LoadSceneAsync(sceneName)` (overload de 1 parâmetro; retorno descartado, método `void`).

`OnActiveSceneChanged(Scene, Scene)` (0x2072644): `IsSceneChangingInProgress = false`,
`Multiplayer_LoadingSceneNameInProgress = null`, `CurrentlyLoadingSceneName = null`.

## Lacunas (para loops seguintes)
- Quem inscreve `OnActiveSceneChanged` em `SceneManager.activeSceneChanged` (ver `docs/RECON_SCENE_SUBSCRIBERS.md`).
- Receptor do evento de rede que carrega a cena depois do ramo multiplayer.
- Invocação do `Action` ao fim do `Fade` (tween) e o corpo de `StartSceneTransition`.
- `LoadScene` não consulta `IsSceneAvailable`; cena inexistente depende do comportamento da Unity.
- Efeitos internos das quatro funções de limpeza de cache e de `MPOwnership.Clear`.
- `mp_nextSceneId` aparece na análise anterior (docs/RECON_CALLBACK_2026-11-03.md) mas não é reverificado pelas sondas.
